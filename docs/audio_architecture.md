# Audio Architecture — HODL THE TOWER (v0.14.1)

## Buses

Defined in [`default_bus_layout.tres`](../default_bus_layout.tres):

| Bus | Role |
|---|---|
| Master | Global volume / mute |
| Music | Meta ambient and future music |
| SFX | All gameplay combat / wave / result cues |
| UI | Command Center UI one-shots |

Settings (`user://settings.json` → `audio`) drive Master / Music / SFX / UI linear volumes. Mute zeros Master.

## UI vs Gameplay

- **UI** — autoload [`UiAudio`](../scripts/app/ui_audio.gd). Focus, accept, back, modal, research, reward, boot. Music-bus ambient bed (`audio/ui/ui_ambient.wav`, looped).
- **Gameplay** — autoload [`GameplayAudio`](../scripts/app/gameplay_audio.gd). Event catalog in [`GameplayAudioCatalog`](../scripts/app/gameplay_audio_catalog.gd). Streams under `audio/sfx/`.

Never put gameplay combat on the UI bus. Never put UI clicks on SFX.

## 3D vs global

| Class | Player | Events |
|---|---|---|
| Spatial | `AudioStreamPlayer3D` at world position | sentry_fire, projectile_hit, guard/enemy attack, melee_hit, deaths, tower_build |
| Global | `AudioStreamPlayer` | wave_start, wave_complete, core_hit, level_complete, game_over |

Attenuation is moderate: a Floor 3 Sentry remains audible from Floor 1, only quieter. `max_distance` / `unit_size` live on the catalog entry.

## Service API

```gdscript
GameplayAudio.play_3d(event_id, world_position)
GameplayAudio.play_global(event_id)
GameplayAudio.set_suppressed(true|false)
GameplayAudio.stop_all()
```

Players are pooled. Each player keeps one permanent `finished` callback; the current `event_id` is stored as metadata on the player and used for cleanup. Voice caps prefer newest events when exceeded (typical: fire/hit 8, melee 6, deaths 5, globals 1–2). Combat micro-SFX use light pitch variance (±2–4%).

## Event catalog

Placeholder WAVs are generated by [`tools/audio/generate_gameplay_sfx.py`](../tools/audio/generate_gameplay_sfx.py) (dry, mechanical, slightly electronic — not cartoon / casino / laser pew). Replace streams without changing call sites.

## Hooks (live only)

| Event | Call site |
|---|---|
| sentry_fire | `basic_tower._fire` |
| projectile_hit | `basic_projectile._apply_hit` |
| guard_attack / enemy_attack | melee `_process_engaged` |
| melee_hit | Guard `take_damage`; Enemy `take_damage` when source is Guard Post |
| enemy_death / guard_death | real death paths |
| tower_build | `_instantiate_tower` when `free == false` |
| wave_start / wave_complete | GameManager wave handlers |
| core_hit | `core.take_hit` |
| level_complete / game_over | `_set_level_complete` / `_set_game_over` |

Do **not** hook `tower_built`, `enemy_spawned`, `wave_state_changed`, or `core_hp_changed` for SFX — they also fire during session restore and Time Machine preview.

## Time Machine

- Entering preview: `set_suppressed(true)` + `stop_all()` before restore.
- Resume Here / Return to Live: restore under suppress, then `set_suppressed(false)`.
- Historical combat/build/death sounds never replay.
- Post-game timeline remains inspect-only (no SFX).

## Rules for future tower sounds

1. Add a catalog entry + WAV; call `play_3d` / `play_global` from the live gameplay function.
2. Gate restores with `free` / dedicated live paths — never restore signals.
3. Respect voice caps; keep combat micro-SFX short and quieter than build/core/wave.
4. No footsteps, flight loops, or per-tower hum until discrete combat language is proven.
5. Audio must never change combat timers, damage, or death delays.
